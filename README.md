# Content Archive

Arquivo de conteúdo gerado pelo agente de repurposing YouTube → Instagram.

## Estrutura

`
posts/        # Posts prontos para publicar (um .md por vídeo)
assets/       # Imagens e mídias dos posts
`

## Como funciona

1. Agente extrai transcrição do YouTube
2. Claude gera caption, hashtags e slides
3. Conteúdo salvo aqui como .md
4. Issue criada para rastreamento
5. Post publicado no Instagram

## Labels

- instagram — conteúdo publicado no Instagram
- youtube — origem do conteúdo
- published — já publicado
- draft — rascunho, ainda não publicado
- eview — aguardando revisão
